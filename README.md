# 古船模型吊装转运与复位放行台

由原帆索校准台升级而来，覆盖转运开单、封帆/拆桅登记、复位校验、复校放行与交付。

## 分层承载

- `store.js` 归档层：JSON 落库，转运单旧版本整体归档（可追溯）。
- `judgment.js` 判定层：开单/改单校验、复位比对、复校人规则、交付资格，判定不过抛 `Reject`。
- `page.js` 页面层：单页界面，只展示与采集输入。
- `server.js` 接入层：HTTP 路由，先判定后落库。

## 规则摘要

- 一个模型同时只能有一张开放转运单（开放 / 待复校 / 已复位）。
- 封帆、拆桅前登记支撑位（每桅至少 2 个）、锁具号、责任人；支撑不足或锁具被他单占用 → 整单拒绝且不落库。
- 复位按原索径、绕向、张力逐项校验；不符不报错，只转「待复校」。
- 复校人须与拆装人不同；每次复校留存比对前值。
- 修改转运单即作废复位与交付资格，旧版整体归档可追溯。
- 复位通过方可交付；交付后锁具释放，模型可再开新单。

## 运行

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/transfer-release.json`，刷新后状态一致。
